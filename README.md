## README

This is the latest release for GradXen client - the student app for computer-based tests.
1. You can download this .EXE file, which is an installer for Windows. 
2. After your download, run this on your Windows PC and install the GradXen client.
3. After installing successfully - The first time, you need to open the client app and create an account using the email that your professor/invigilator/admin registered on GradXen for you. 
4. Once you have registered, you can always log in using the same email-password combination when you have a test scheduled via GradXen.

Happy testing!
